《前进四 / ADVANCE FOUR》立项方案

一、游戏定位
类型：
宇宙飞船设计 + 幸存者战斗 + Roguelike 路线推进

核心体验：
玩家亲手设计并改装飞船，在星系中不断前进，通过战斗、事件与资源获取强化舰船，最终打通通往新世界的航线。

一句话概括：
“一款可以亲手拼装宇宙飞船的幸存者类 Roguelike。”

二、核心循环
设计飞船
→ 选择星系路线
→ 进入战斗 / 事件
→ 获取资源与模块
→ 修理、扩建、改装飞船
→ 挑战星系 Boss
→ 建立穿梭节点
→ 前往下一个星系

三、飞船设计系统
参考：StarDrive

飞船由方格模块组成，玩家可自由调整舰体结构。

主要模块：
1. 武器：机炮、激光、导弹、轨道炮
2. 动力：主引擎、转向推进器
3. 能源：反应堆、电池
4. 防御：装甲、护盾
5. 功能：雷达、维修、无人机、机库
6. 特殊：跃迁、EMP、异文明科技

核心原则：
模块位置必须影响实际性能。

例如：
- 武器射界以安装时的炮口方向为中心，随船体旋转；炮塔只能在射界内转动。
- 战斗中弹丸沿当前炮口方向发射，显示炮口、炮塔转动范围与实际射界保持一致。
- 引擎需要喷射空间
- 反应堆被摧毁会导致能源不足
- 外层装甲保护内部模块
- 舰体重量影响速度和转向

玩家设计的飞船形状，本身就是战斗流派。

四、战斗系统
参考：《土豆兄弟》

形式：
俯视角实时战斗。

操作：
- 玩家控制飞船移动
- 玩家控制舰首朝向
- 武器自动攻击或半自动攻击

特点：
- 大量敌舰持续出现
- 战斗节奏快
- 单场时间短
- 强调走位、朝向和 Build
- 飞船模块可以被局部破坏


五、舰船损伤系统
飞船不是统一血条，而是模块化受损。

例如：
反应堆受损
→ 能源下降
→ 护盾关闭
→ 武器效率降低

引擎受损
→ 速度下降
→ 转向能力降低

武器被摧毁
→ 对应火力直接消失

核心目的：
让玩家从战斗失败中学习舰船设计。

六、地图系统
参考：《杀戮尖塔》

“章节”改为“星系”。
“节点”改为星球、空间站、小行星带、遗迹、异常区域等。

节点类型：
- 普通战斗
- 精英战斗
- 商店
- 资源点
- 废弃空间站
- 文明事件
- 科技遗迹
- 修理点
- Boss

玩家每次只能沿航线继续前进，原则上不能返回已经离开的星系。

七、星系推进
每个星系相当于一个章节。

流程：
进入星系
→ 选择航线
→ 探索多个节点
→ 强化飞船
→ 击败星系 Boss
→ 建立穿梭节点
→ 前往下一星系

最终目标：
一步一步打通通往目标类地行星的航线。

八、资源系统
控制在少量核心资源。

1. 合金
用于舰体、装甲、维修。

2. 能源核心
用于高级武器、引擎、反应堆。

3. 数据
用于科技、蓝图、永久解锁。

当前 Prototype（v0.36）已先使用 Credits + Run Inventory 验证战后经济闭环：
- 战斗胜利获得 Credits。
- Hull 战损会保留到下一场战斗。
- 战果页支持选择单个受损 Hull 进行局部维修，也保留“全部维修”。
- 当前维修费用规则为 1 缺失 Hull HP = 1 Credit。
- Equipment 本身不维护独立 HP；其效率由覆盖 Hull Cell 的健康度决定，因此修复承载区域会恢复对应模块效率。
- 战斗可固定奖励模块与 Hull 库存；Run 整备时新增 Hull / Equipment 必须消耗库存，拆除会返还库存，移动 / 旋转免费。
- 战后成长奖励可配置为多选一候选；Credits 立即结算，模块/Hull 候选必须先选择 1 项，领取后才能进入整备或下一战。
- stage_001 战果页可进入补给商店，用 Credits 购买模块或 Hull，购买结果直接进入 Run Inventory。
- 这是当前 Prototype 的临时经济验证层，后续正式资源体系仍按合金 / 能源核心 / 数据方向迭代。

九、Roguelike 成长
局内成长：
- 获得新模块
- 扩大舰体
- 强化模块
- 形成流派
- 获取异文明科技

局外成长：
- 解锁新模块
- 解锁新舰体
- 解锁新文明科技
- 解锁新的初始舰船方案

重点：
减少单纯“+10%伤害”式成长，多做能够改变飞船结构和玩法的成长。

十、Boss 设计
Boss 同样遵守模块规则。

玩家可以针对：
- 武器系统
- 引擎
- 护盾发生器
- 反应堆
- 舰桥

不同破坏顺序产生不同战术。

Boss 应该是“飞船设计题”，而不仅是高血量敌人。

十一、世界观与玩法结合
地球已经无法继续支撑人类文明。

人类投入最后资源，向遥远的新世界迁徙。

玩家所在舰队必须不断建立穿梭节点，穿越其他文明控制的星域，最终抵达目标星球。

核心主题：没有退路，前进四。

十二、项目核心卖点
最重要的三个系统：

模块化飞船设计
+
模块化舰船损伤
+
幸存者式实时战斗

最终形成：

“怎么造船”
决定
“怎么战斗”

“怎么战斗”
又决定
“下一次怎么造船”

这是《前进四》的核心玩法闭环。
