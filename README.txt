《前进四 / ADVANCE FOUR》立项方案

一、游戏定位
类型：
宇宙飞船设计 + 幸存者战斗 + Roguelike 路线推进

核心体验：
玩家亲手设计并改装飞船，在星系中不断前进，通过战斗、事件与资源获取强化舰船，最终打通通往新世界的航线。

一句话概括：
“一款可以亲手拼装宇宙飞船的幸存者类 Roguelike。”

二、核心循环
设计飞船
→ 选择星系路线
→ 进入战斗 / 事件
→ 获取资源与模块
→ 修理、扩建、改装飞船
→ 挑战星系 Boss
→ 建立穿梭节点
→ 前往下一个星系

三、飞船设计系统
参考：StarDrive

飞船由方格模块组成，玩家可自由调整舰体结构。

主要模块：
1. 武器：机炮、激光、导弹、轨道炮
2. 动力：主引擎、转向推进器
3. 能源：反应堆、电池
4. 防御：装甲、护盾
5. 功能：雷达、维修、无人机、机库
6. 特殊：跃迁、EMP、异文明科技

核心原则：
模块位置必须影响实际性能。

例如：
- 武器射界以安装时的炮口方向为中心，随船体旋转；炮塔只能在射界内转动。
- 战斗中弹丸沿当前炮口方向发射，显示炮口、炮塔转动范围与实际射界保持一致。
- 引擎需要喷射空间
- 反应堆被摧毁会导致能源不足
- 外层装甲保护内部模块
- 舰体重量影响速度和转向

玩家设计的飞船形状，本身就是战斗流派。

四、战斗系统
参考：《土豆兄弟》

形式：
俯视角实时战斗。

操作：
- 玩家控制飞船移动
- 玩家控制舰首朝向
- 武器自动攻击或半自动攻击

特点：
- 大量敌舰持续出现
- 战斗节奏快
- 单场时间短
- 强调走位、朝向和 Build
- 飞船模块可以被局部破坏


五、舰船损伤系统
飞船不是统一血条，而是模块化受损。

例如：
反应堆受损
→ 能源下降
→ 护盾关闭
→ 武器效率降低

引擎受损
→ 速度下降
→ 转向能力降低

武器被摧毁
→ 对应火力直接消失

核心目的：
让玩家从战斗失败中学习舰船设计。

六、地图系统
参考：《杀戮尖塔》

“章节”改为“星系”。
“节点”改为星球、空间站、小行星带、遗迹、异常区域等。

节点类型：
- 普通战斗
- 精英战斗
- 商店
- 资源点
- 废弃空间站
- 文明事件
- 科技遗迹
- 修理点
- Boss

玩家每次只能沿航线继续前进，原则上不能返回已经离开的星系。

七、星系推进
每个星系相当于一个章节。

流程：
进入星系
→ 选择航线
→ 探索多个节点
→ 强化飞船
→ 击败星系 Boss
→ 建立穿梭节点
→ 前往下一星系

最终目标：
一步一步打通通往目标类地行星的航线。

八、资源系统
当前 Prototype 使用两种局内资源：

1. 能量结晶
宇宙通用的交易通货。
主要用于：
- 补给商店购买模块
- 补给商店购买 Hull
- 后续其他交易型节点

2. 零件
工程维护与制造资源。
当前用于：
- 战后维修受损 Hull
- 未来维修改装空间站制造模块

当前规则：
- 1 缺失 Hull HP = 1 零件。
- Equipment 本身仍不维护独立 HP；其效率由覆盖 Hull Cell 的健康度决定，因此维修 Hull 会恢复对应模块效率。
- 商店只消耗能量结晶，不消耗零件。
- 维修只消耗零件，不消耗能量结晶。
- 战斗可以同时奖励能量结晶、零件和模块战利品。
- 空间站已支持零件制造模块并存入仓库。

九、Roguelike 成长
局内成长：
- 获得新模块
- 扩大舰体
- 强化模块
- 形成流派
- 获取异文明科技

局外成长：
- 解锁新模块
- 解锁新舰体
- 解锁新文明科技
- 解锁新的初始舰船方案

重点：
减少单纯“+10%伤害”式成长，多做能够改变飞船结构和玩法的成长。

十、Boss 设计
Boss 同样遵守模块规则。

玩家可以针对：
- 武器系统
- 引擎
- 护盾发生器
- 反应堆
- 舰桥

不同破坏顺序产生不同战术。

Boss 应该是“飞船设计题”，而不仅是高血量敌人。

十一、世界观与玩法结合
地球已经无法继续支撑人类文明。

人类投入最后资源，向遥远的新世界迁徙。

玩家所在舰队必须不断建立穿梭节点，穿越其他文明控制的星域，最终抵达目标星球。

核心主题：没有退路，前进四。

十二、项目核心卖点
最重要的三个系统：

模块化飞船设计
+
模块化舰船损伤
+
幸存者式实时战斗

最终形成：

“怎么造船”
决定
“怎么战斗”

“怎么战斗”
又决定
“下一次怎么造船”

这是《前进四》的核心玩法闭环。





v0.45.0 战后结算：
- 战利品和胜利结果合并为一个界面，不再选择额外成长奖励。
- 战损以真实飞船模块快照呈现；点击船体格查看并维修，支持缩放/拖动。
- 战利品逐件带走或放弃后即可继续；维修可跳过。


v0.45.1 战斗结束规则：
- 删除战斗结果确认弹窗；胜利直接进入统一结算。
- 失败即 Game Over，结束并清空本次 Run；只有返回整备，不再重新挑战。
