以下早期版本说明仅作历史留档。

game/run/warehouse

职责：
- 当前 Run 的模块仓库管理场景。
- 展示模块仓储 Used / Capacity、超载状态与 Hull Stock。
- 同 ID 模块堆叠显示，不进行二维拼格。
- 支持按 ModuleType 筛选与查看完整模块属性。

第一版交互：
- 左侧：库存模块列表，显示图标、名称、尺寸、数量与总仓储占用。
- 右侧：模块完整详情。
- 货舱模块额外显示“安装后仓储容量”与“净仓储贡献”。
- “前往整备”仅在路线规则允许进入 REFIT 节点时启用，不提供免费整备。
- “返回大地图”不会修改当前路线节点。

边界：
- 当前不支持出售、分解、收藏、拖拽整理或仓库二维摆放。
- Hull Stock 独立保存，不计入模块仓储。
