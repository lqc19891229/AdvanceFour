《前进四》game/combat/dev 目录说明

用途：存放战斗流程的独立开发检查。

当前文件：
- combat_regression_test.gd：SceneTree 无界面运行入口。

验证范围：
- 准备、波间计时和分批生成；尚未生成的敌舰阻止提前完成波次。
- 玩家局部战损跨波次保留。
- 残留弹丸结束前不判胜；末敌先死亡后，它已发射的弹丸仍可击毁玩家并判失败。
- 同帧双方核心摧毁时失败优先；结果只发出一次，结束后停止移动、计时和生成。
- 实际敌舰弹丸穿过同方模块，玩家弹丸可以命中同一敌方模块。
- HUD / 结算布局、配置与存档错误、编辑器出航、结果按钮重开和返回设计。

使用：
python3 tools/verify_project.py --godot /path/to/godot
统一工具先执行飞船回归，再执行本目录战斗回归；临时用户数据不写回玩家存档。
界面检查使用 1152×648 逻辑窗口，避免 Godot headless --script 默认 64×64 尺寸造成误判。
