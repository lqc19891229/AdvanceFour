【边界】
tools：Excel 源表、JSON 中间缓存、导入与验证工具；不作为运行时数据源。
data：定义、实例、正式素材、玩家/敌人可共用的飞船模板。
game：玩法逻辑、控制器、编辑器、渲染器、UI、测试。
core：跨场景全局状态服务。
addons：编辑器导入流程。
用户可写存档：user://ships/test_ship.json，不在 res://data/ 内。

【关键数据链】
Equipment：tools/data_source/module_data.xlsx → tools/import/import_excel.py → tools/cache/modules.json → addons/advance_four_data_importer/ → data/modules/*.tres + module_database.tres。
舰船：data/ships/templates/*.json → ShipSerializer → ShipData → ShipRuntime。
敌舰：data/enemies/*.tres (EnemyShipDefinition.ship_template_path) → EnemyShipFactory → ShipSerializer → ShipData → ShipRuntime；EnemyController 负责接近/后退，不直接处理物理或武器。
玩家：星图启动取 user://ships/test_ship.json 的有效设计，否则使用 Battle.build_starter_design()；运行时复制到 RunState.current_ship。
战斗：BattleDefinition + BattleWaveDefinition → game/combat/battle.gd；胜利自动结算，失败进入 Game Over。
编辑器：game/ship/editor 处理用户设计/Run 库存改装；game/ship/template_editor 是独立开发工具，共用 ShipGridView，不写 RunState。

【当前运行规则】
Run 货币为 energy_crystals（交易）与 parts（维修、制造），不是旧 Credits。
游戏默认固定测试航线；RouteMapGenerator.generate() 不用于默认开局。
战利品与维修合并在 battle_result_screen；胜利无需二次确认，失败不能 Retry。
旧 EnemyRuntime 与 Python __pycache__ 已从仓库清理。

【验证】
python3 tools/verify_project.py --godot /path/to/godot
CI：.github/workflows/project-checks.yml。此文件描述当前目录，不存放历史版本规则；版本历史见 VERSION_HISTORY.txt。
