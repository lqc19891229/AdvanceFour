========================================
一、四个核心目录的边界
========================================

1. tools：生产内容
   - 策划源表、源素材、缓存、导入脚本、验证工具。
   - 不作为游戏 Runtime 的正式资源路径。
   - art_source 使用 .gdignore，防止重复导入。

2. data：描述内容
   - 游戏运行时加载的数据结构、配置实例和正式素材。
   - definitions 是数据“类型/结构”；modules/enemies/battles 是具体实例。
   - assets 是 Runtime 正式素材。
   - 不再存在 generated 层级。
   - 自动生成文件直接归入对应业务目录。

3. game：执行内容
   - 场景、Node、Controller、Runtime、Renderer、Gameplay、UI、开发测试。
   - 不保存策划源数据、纯 Definition 类或正式 PNG 素材。

4. core：支撑整个项目
   - 跨场景、跨系统共享的底层服务。
   - 不放 Ship / Weapon / Battle 等具体玩法规则。

判断：
“它是什么？” → data
“它怎么运行？” → game
“它怎么被制作出来？” → tools
“所有系统都需要的底层能力？” → core


========================================
二、数据链
========================================

模块数值：
tools/data_source/game_data.xlsx
→ tools/import/import_excel.py
→ tools/cache/modules.json
→ addons/advance_four_data_importer
→ data/modules/<type>/<module_id>.tres
→ data/modules/module_database.tres

模块素材：
tools/art_source/modules/
→ 正式 Runtime 版本
→ data/assets/modules/
→ ModuleDefinition.texture / Weapon.turret_texture

说明：
Excel 当前旧行若仍含历史 game/ship/art/modules 路径，Python importer 会规范化为 data/assets/modules；
新数据应直接填写 data/assets 路径。


========================================
三、数据定义与实例
========================================

data/definitions/module/
- ModuleDefinition 及 Energy/Propulsion/Weapon/Defense/Function/Core 子类
- ModuleDatabase 类型

data/definitions/ship/
- ShipData
- ShipHullCell
- ShipModuleInstance
- ShipSerializer

data/definitions/combat/
- BattleDefinition
- BattleWaveDefinition
- EnemyShipDefinition

具体实例：
- data/modules/
- data/enemies/
- data/battles/

definitions 不承担 Gameplay 执行。


========================================
四、正式战斗结构
========================================

data/battles/stage_001.tres
↓
BattleDefinition
↓
BattleWaveDefinition
↓
EnemyShipDefinition（data/enemies）
↓
ShipData
↓
game/combat/battle.tscn / Battle

Battle 只执行配置，不定义具体关卡内容。
重新挑战保持当前 BattleDefinition。
显式 battle_definition_path 无效时进入 ERROR，不回退默认关卡。


========================================
五、飞船分层
========================================

Data：
ShipData
├─ Hull Layout → ShipHullCell
└─ Equipment → ShipModuleInstance → ModuleDefinition

Runtime：
ShipRuntime
├─ HullCellRuntime
├─ WeaponRuntime
├─ ProjectileRuntime
├─ Player / AI Controller
└─ Appearance Layer

数据结构属于 data，运行实体属于 game。


========================================
六、自动生成规则
========================================

不通过 generated 目录区分自动生成内容。

当前自动生成：
- data/modules/<type>/*.tres
- data/modules/module_database.tres

来源：
- tools/data_source/game_data.xlsx

生成器：
- tools/import/import_excel.py
- addons/advance_four_data_importer

这些文件是否允许手工修改，由 data/modules README 明确规定。
