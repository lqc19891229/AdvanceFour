《前进四》tools/data_source 目录说明

职责：
保存策划可直接编辑的数据源。

当前：
- game_data.xlsx：模块策划数值唯一真源。

工作流：
修改 Excel
→ 运行导入/验证
→ 更新 tools/cache/modules.json
→ 生成 data/modules 下的正式 Runtime Resource。

尺寸与武器美术填写：
- 六张模块页统一使用“高X宽”列：例如 2x1 表示高 2 格、宽 1 格；1x1 表示一格。
- Weapon 的“炮塔高X宽”独立于底座占格：长炮管可以填 2x1，底座仍填 1x1。
- “炮塔轴点”“炮口”各使用一个文本格，填写 X,Y，例如 0.5,0.25 / 0.5,0.98。
- 坐标以朝上后的完整图片（包括透明留白）为准：左下角 (0,0)，右上角 (1,1)；X 向右增加，Y 向上增加。
- 例如 128×256 图片，从左上角数的像素轴点 (64,192)，填写 64/128,1-192/256，即 0.5,0.25。
- 炮口像素点 (64,5.12) 对应 0.5,0.98。数值需要按素材中实际炮口位置调整。
- 新素材默认朝上；“炮塔素材转角（度）”可留空或填 0。现有朝右机炮填 -90，兼容旧素材而不修改源 PNG。
- 尺寸支持 x、X、×，必须为正整数；坐标必须为 0～1 有限数字，支持英文或中文逗号。
- 导入后运行 tools/generate_weapon_icon.gd 重建武器图标，再让 Godot 导入图片。
