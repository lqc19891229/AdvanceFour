《前进四 / ADVANCE FOUR》制作流程计划 V0.1

一、项目目标

游戏类型：
宇宙飞船设计 + 幸存者实时战斗 + Roguelike 路线推进

核心验证目标：
优先证明“拼飞船 + 开出去战斗 + 根据战损继续改船”是否足够有趣。

开发原则：
1. 先做核心玩法，不先堆内容。
2. 先做最小可玩版本，再逐步增加复杂度。
3. 飞船设计与战斗必须互相影响。
4. 所有后续系统都围绕核心循环服务。


二、总体开发顺序

阶段 1：基础飞船编辑器
目标：
让玩家能够快速拼出一艘可以进入战斗的飞船。

需要实现：
- 方格舰体
- 模块放置
- 模块拆除
- 模块旋转
- 基础舰体结构限制
- 保存当前飞船配置
- 加载当前飞船配置

首批模块只做：
- 武器
- 引擎
- 反应堆
- 装甲

暂时不做：
- 稀有度
- 科技树
- 大量武器
- 复杂资源
- 高级 UI

完成标准：
玩家可以在 1～2 分钟内完成一艘简单飞船，并进入测试场景。


阶段 2：基础战斗原型
目标：
验证“玩家自己设计的飞船开起来是否有趣”。

需要实现：
- 俯视角飞船移动
- 飞船朝向控制
- 自动攻击
- 基础敌人 AI
- 敌人生成
- 飞船碰撞
- 基础生命值
- 战斗结束条件

敌人数量：
先做 2～3 种。

建议：
- 追击型
- 远程射击型
- 快速冲锋型

战斗场景：
先使用空旷宇宙测试场。

单场时间：
3～5 分钟。

完成标准：
不同飞船结构已经能够产生明显不同的战斗体验。


阶段 3：模块规则
目标：
让“怎么摆模块”真正影响飞船性能。

优先实现：
- 武器射界
- 武器安装方向
- 引擎推进方向
- 能源供给
- 能源消耗
- 舰体重量
- 飞船速度
- 飞船转向
- 模块工作状态

示例：
反应堆能源不足时，
部分武器、护盾或引擎无法满功率工作。

完成标准：
玩家开始因为性能问题主动调整飞船结构。


阶段 4：模块化损伤
目标：
建立《前进四》最重要的核心特色。

需要实现：
- 每个模块拥有独立耐久
- 攻击命中具体模块
- 外层装甲可以保护内部模块
- 武器损坏后停止攻击
- 引擎损坏后影响机动
- 反应堆损坏后影响供能
- 模块完全摧毁
- 战斗结束后保留损伤结果

可后续增加：
- 爆炸伤害
- 连锁损伤
- 火灾
- 能源过载
- 模块失效但未完全摧毁

完成标准：
玩家战斗后会自然产生：

“这里太脆了。”
“反应堆应该往里面放。”
“引擎需要更多保护。”

如果玩家开始主动根据战损修改飞船，核心玩法基本成立。


阶段 5：战斗奖励与改船
目标：
形成最初的 Roguelike 成长循环。

战斗结束后提供：
- 新模块
- 合金
- 修理机会
- 舰体扩展

第一版奖励可以采用：
三选一。

例如：
- 武器模块
- 功能模块
- 舰体扩展

基本循环：

战斗
→ 奖励
→ 改船
→ 下一场战斗

完成标准：
玩家能够连续经历多场战斗，并逐渐把初始小船改造成不同流派。


阶段 6：完整单局原型
目标：
做出第一个真正可以玩的 Run。

流程：

初始造船
→ 战斗
→ 奖励
→ 改船
→ 战斗
→ 奖励
→ 改船
→ 精英战
→ 奖励
→ 改船
→ Boss

暂时不要加入复杂地图。

建议单局长度：
15～30 分钟。

完成标准：
即使没有剧情、星系地图和正式美术，也愿意重复游玩数局。


阶段 7：Boss 系统
目标：
验证大型模块化敌舰是否成立。

第一只 Boss 不追求数量和演出。

需要实现：
- 大型舰体
- 多个独立武器模块
- 引擎
- 反应堆
- 装甲区域
- 模块弱点
- 不同阶段行为

玩家可以选择：
- 先拆武器
- 先打引擎
- 先破坏能源
- 直接攻击核心

完成标准：
Boss 战不是单纯打血条，而是在“拆飞船”。


阶段 8：星系地图系统
目标：
加入类似《杀戮尖塔》的路线选择。

结构：
章节 = 星系
节点 = 星球 / 空间站 / 小行星带 / 遗迹 / 战斗区域

第一版节点类型：
- 普通战斗
- 精英战斗
- 商店
- 事件
- 修理
- Boss

核心：
玩家只能继续向前推进，不随意返回已经离开的星系。

完成标准：
路线选择可以产生风险与收益决策，而不是单纯选择不同背景。


阶段 9：资源与商店
目标：
丰富玩家的中期决策。

推荐核心资源：

1. 合金
用途：
- 修理
- 舰体
- 装甲

2. 能源核心
用途：
- 高级武器
- 引擎
- 高级能源模块

3. 数据
用途：
- 蓝图
- 科技
- 特殊解锁

商店功能：
- 购买模块
- 出售模块
- 修理
- 舰体扩展
- 特殊服务

完成标准：
玩家需要在修理、购买、扩建之间做取舍。


阶段 10：事件系统
目标：
加强宇宙航行感和世界观表现。

事件类型：
- 废弃空间站
- 求救信号
- 文明接触
- 小行星矿区
- 异文明遗迹
- 海盗勒索
- 舰船残骸
- 特殊天体现象

事件应尽量影响：
- 资源
- 模块
- 舰体
- 后续路线
- 文明关系
- 战斗状态

避免：
纯文本、纯数值、与核心玩法完全无关的事件。


阶段 11：Build 与模块体系
目标：
系统化扩展玩法流派。

优先规划流派：

1. 正面重炮舰
特点：
舰首火力集中。

2. 侧舷炮舰
特点：
侧面火力强。

3. 导弹舰
特点：
远程、风筝。

4. 激光舰
特点：
高能源、高持续输出。

5. 无人机母舰
特点：
召唤、控制距离。

6. 冲撞舰
特点：
重甲、高速度。

7. 高速闪避舰
特点：
轻型、高机动。

8. 玻璃大炮
特点：
极高火力、极低生存。

完成标准：
玩家拿到不同模块后，会明显改变造船思路。


阶段 12：局外成长
目标：
增加长期游玩动力。

推荐解锁内容：
- 新初始舰体
- 新武器模块
- 新功能模块
- 新文明科技
- 新飞船蓝图
- 新事件
- 新 Boss
- 新星系

原则：
优先“增加选择”，少做永久数值碾压。

例如：
推荐：
解锁新的初始反应堆。

不推荐：
永久伤害 +30%。


阶段 13：世界观与剧情整合
目标：
让玩法与《前进四》的主题统一。

核心背景：
地球资源枯竭。
人类最后的殖民舰队向新世界前进。

玩家需要：
- 穿越多个星系
- 建立穿梭节点
- 接触其他文明
- 打通航线
- 最终抵达目标类地行星

核心主题：

没有退路。
继续前进。

前进四。

玩法表现：
- 星系只能向前推进
- 每次路线选择不可轻易撤回
- 舰队资源持续消耗
- 不同文明会影响玩家前进方式


阶段 14：正式美术与表现
在核心玩法稳定后再大量投入。

需要逐步完善：
- 飞船模块美术
- 武器特效
- 爆炸效果
- 战损效果
- 宇宙背景
- 星球
- 星系地图
- UI
- 音效
- 音乐
- Boss 演出

重点：
模块必须易于辨识。

玩家需要一眼看出：
- 武器在哪里
- 引擎在哪里
- 反应堆在哪里
- 哪些模块已经损坏


三、开发里程碑

里程碑 1：Prototype 1
内容：
飞船编辑器 + 基础战斗。

验证：
“造船后开出去打”是否有基础乐趣。


里程碑 2：Prototype 2
内容：
模块规则 + 模块损伤。

验证：
飞船结构是否真正影响战斗。

这是整个项目最重要的里程碑。


里程碑 3：Core Loop
内容：
战斗 + 奖励 + 改船 + 多场连续战斗。

验证：
Roguelike Build 是否成立。


里程碑 4：Vertical Slice
内容：
完整小型 Run + Boss。

流程：
造船
→ 多场战斗
→ 强化
→ Boss

验证：
游戏是否已经具备可以公开展示的核心体验。


里程碑 5：Alpha
内容：
- 星系地图
- 商店
- 事件
- 多种流派
- 多个 Boss
- 基础局外成长

验证：
完整游戏结构是否成立。


里程碑 6：Content Alpha
内容：
增加：
- 星系
- 文明
- 模块
- 敌人
- Boss
- 事件
- 舰体

重点：
扩充内容，而不是继续频繁推翻核心系统。


里程碑 7：Beta
重点：
- 数值平衡
- Build 平衡
- 难度曲线
- UI
- 操作手感
- 新手教学
- 性能优化
- Bug 修复


里程碑 8：Release Candidate
重点：
- 完整流程测试
- 存档稳定性
- 极端 Build 测试
- 性能
- 本地化
- 成就
- Steam 功能
- 最终平衡


四、最优先验证的问题

开发过程中始终优先回答以下问题：

1. 拼飞船本身是否有趣？
2. 不同结构是否真的改变战斗方式？
3. 玩家是否能看懂自己为什么输？
4. 战损是否会刺激玩家重新设计飞船？
5. 新模块是否会让玩家改变 Build？
6. 飞船变大后是否越来越有成就感？
7. 战斗是否足够爽快，而不是被复杂系统拖慢？
8. 玩家是否愿意重新开始下一局？


五、暂时不要优先做的内容

核心玩法验证前，不建议大量投入：

- 大量剧情
- 大量文明设定
- 复杂外交系统
- 完整科技树
- 数百种模块
- 多种资源体系
- 正式过场动画
- 大量星系
- 大量 Boss
- 完整成就系统
- 联机
- PVP
- 舰队级控制
- 复杂船员系统

这些系统都可以以后增加。

当前唯一目标：

先证明一艘玩家自己拼出来的飞船，在战场上真的很好玩。

七、核心制作原则

整个开发过程中优先保护这一条循环：

设计飞船
↓
进入战斗
↓
发现设计问题
↓
获得新模块
↓
重新设计
↓
再次战斗

只要这个循环持续有趣，
《前进四》的主体就成立。

其他系统：
地图、事件、剧情、文明、资源、局外成长，
都应该围绕这个核心循环进行扩展。
