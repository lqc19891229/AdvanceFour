《前进四》开发状态 v0.31.13

当前阶段：模块化飞船战斗 Prototype，尚未形成完整 Roguelike 游戏。

已完成：
- 飞船数据已拆为 Hull Layout + Equipment 两层；网格编辑器可独立铺设基础船体格并在其上安装/移动/旋转设备。
- Excel → Python → JSON cache → Godot 插件 → .tres 继续负责 Equipment 定义；Equipment 已取消 mass，共通 hp 也已移除，只有 Defense 保留 hp。Hull Cell 独立保存位置、max_hp/current_hp、质量与 hull_type。
- 玩家移动与转向、核心中心原点、独立炮塔自动选敌与射击。
- 模块贴图已纳入正式数据链：Excel 各模块 Sheet 使用 texture_path，Weapon 额外使用 turret_texture_path；导入后写入 JSON cache、模块 .tres 与 ModuleDatabase，不再由代码按 module_id 固定拼接路径。
- 首批模块 PNG 已提交并完成数据挂载；武器视觉拆为底座 + 炮塔。v0.31.11 新增独立 Appearance Layer：战斗中根据 Hull Layout 自动绘制连续外壳，Core / Weapon / Propulsion 外露，Energy / Defense / Function 被船壳包覆；编辑器仍完整显示 Hull + Equipment。
- 弹丸 swept ray 改为命中独立 Hull Cell 碰撞体；每个 Hull Cell 独立承伤并支持 HP-overkill 穿透。
- 武器火力、攻击范围、射击间隔、炮塔转速、弹速、射界和开火角容差已进入 Excel → JSON → .tres 数据链；不同武器可使用独立数值。weapon_cannon 当前射界为 180°。
- 攻击范围同时用于自动选敌和弹丸最大飞行距离；弹丸记录开火时射程与弹速，走完后消失，最后一帧不越界命中。
- 除 Defense 外 Equipment 不再拥有 hp；区域最大 HP = ShipHullCell.max_hp + 覆盖该区域的 Defense.hp。多格 Defense 的 hp 平均分配到覆盖区域。Equipment 效率仍取覆盖 Hull Cell 健康度平均值，核心覆盖 Hull 全毁时整船移除。
- 敌舰 AI：选择最近有效玩家目标、转向追踪、接近与倒车保持距离。
- 编辑器 → 单敌舰交火测试 → 返回编辑器并恢复设计。
- 飞船移动已改为纯推力模型：最高速度、加速度与松油减速度只由当前有效引擎推力乘对应 scale 决定；Hull / Equipment 质量不参与移动计算。
- 当前移动参数为 speed_scale = 2.5、acceleration_scale = 1.0、deceleration_scale = 1.5、reverse_thrust_ratio = 0.5；动力所在 Hull 受损或断电会同步降低有效推力，从而降低最高速度和加减速能力。
- 飞船编辑器属性顶部显示预计最高速度，随模块布局变化更新，并提示供能不足。
- 飞船编辑器支持 Hull/Equipment 分层操作：Hull 格独立放置/拆除；Equipment 只能完整安装在 Hull 上，并支持选中、移动、旋转，保留实例 uid。
- 战斗世界固定星点 / 网格参照，HUD 显示实时速度与坐标，明确前进 / 倒车 / 转向操作。
- 单场战斗：有限波次、逐个生成敌舰、HUD、胜负结算、重开 / 返回。
- v0.31.13 将 battle.tscn 正式化为所有关卡共用的战斗容器；新增 BattleDefinition Resource 与 definitions/stage_001.tres。飞船编辑器只负责验证/保存设计并选择关卡配置，不再承载战斗规则。后续普通关卡、精英战与 Boss 战均应复用 battle.tscn，通过 BattleDefinition 数据化差异。
- 最终清场后等待空中弹丸结束；核心 Equipment 所覆盖 Hull 全部损毁时判定失败，失败优先于同帧胜利。
- 自动检查源表完整性、源表与缓存一致性、generated 贴图引用以及 Godot 物理 / 场景回归；模块重新导入后 ModuleDatabase 已同步持有 Texture2D 引用。
- v0.31.8 完成数据导入技术收口：Excel 解析前强制清理旧 cache，避免解析失败时误读历史 modules.json；全部模块先构建验证后再替换 generated 资源，写入失败会恢复导入前的模块 .tres 与 ModuleDatabase。
- 飞船编辑器待放置/移动预览继续使用红绿合法性提示，同时显示模块真实贴图；新增回归覆盖模块贴图数据链、Runtime 视觉与编辑器 weapon base/turret 预览。

当前入口：
1. F5 运行默认飞船编辑器，完成合法设计，点击“出航战斗”。
2. WASD / 方向键驾驶，清除三波敌舰后结算；R 重开，Esc 返回编辑器。
3. 可 F6 单独运行 game/combat/battle.tscn；默认使用 definitions/stage_001.tres，无存档时使用调试示例船。
4. “敌舰 AI 测试”和旧 ship_movement_test.tscn 保留为独立诊断入口。
