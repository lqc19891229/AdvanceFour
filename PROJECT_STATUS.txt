《前进四》开发状态 v0.30

当前阶段：模块化飞船战斗 Prototype，尚未形成完整 Roguelike 游戏。

已完成：
- 六类模块定义、自由分离布局、网格编辑器、设计保存与加载。
- Excel → Python → JSON cache → Godot 插件 → .tres 数据链；模块独立 hp。
- 玩家移动与转向、核心中心原点、独立炮塔自动选敌与射击。
- 弹丸 swept ray、独立模块碰撞、装甲减伤与 HP-overkill 穿透。
- 武器 / 动力 / 能源局部摧毁效果，模块供电分配，核心摧毁整船移除。
- 敌舰 AI：选择最近有效玩家目标、转向追踪、接近与倒车保持距离。
- 编辑器 → 单敌舰交火测试 → 返回编辑器并恢复设计。
- 自动检查源表完整性、源表与缓存一致性以及 Godot 物理 / 场景回归。

当前入口：
1. F5 运行默认飞船编辑器，完成合法设计，点击“敌舰 AI 测试”。
2. 测试中 WASD / 方向键驾驶，R 重开，Esc 返回编辑器。
3. 无存档时可 F6 单独运行 game/ship/dev/ship_ai_test.tscn，自动使用数据驱动示例设计。
4. 旧 ship_movement_test.tscn 保留为静止目标的局部命中诊断场景。

下一阶段：
1. 战斗流程：敌舰生成、有限波次或计时、正式胜负判定与结算界面。
2. 战后奖励、受损模块状态的延续、维修 / 改装，再进入下一场战斗。
3. 连续战斗与首个模块化 Boss，形成完整 Prototype 核心闭环。
4. 之后再扩展星系航线、商店、事件、模块 Build、局外解锁及正式美术音效。

需要设计确认的扩展：
- 交火测试当前复制玩家布局作为对手；正式敌舰蓝图及强度尚未定义。
- AI 距离与转向参数、炮塔射程 / 射速等仍为 Prototype 参数，尚未进入 Excel。
- 现有炮塔可全周旋转；正式射界、引擎喷射空间、阵营 / 友伤规则尚未实现。
- 本次交火不是正式胜利结算；存档仅保存设计，战损不写回设计。
- 继续保留模块可分离、不相邻、不连通和任意空格的规则。
